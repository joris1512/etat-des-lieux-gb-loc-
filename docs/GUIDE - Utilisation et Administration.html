📋1. L'application en bref

À partir d'un devis PDF, l'application lit le devis, reconnaît chaque module (bungalow, sanitaire, container…), choisit le bon modèle Excel et pré-remplit les états des lieux (un fichier par état + un ZIP). Elle garde aussi la mémoire des clients, chantiers et devis.

C'est un outil interne, qui tourne sur votre serveur / vos postes — rien n'est public sur internet.

🔑2. Ouvrir l'application & se connecter tout le monde

1
Sur le Bureau, double-cliquez sur « GB Etats des lieux ». Une fenêtre s'ouvre.
2
Une page de connexion s'affiche : entrez votre identifiant et votre mot de passe.
3
Vous voilà sur le tableau de bord. Vous restez connecté 7 jours (pas besoin de retaper le mot de passe chaque matin).
Chaque personne a son propre compte (c'est l'administrateur qui les crée — voir §4). Les identifiants ne se partagent pas : ça permet de savoir qui a fait quoi.

⚡3. Générer un état des lieux commerciaux

1
Menu « Générer » → déposez le devis PDF (glisser-déposer ou cliquer pour parcourir).
2
Cliquez « Analyser le devis ». L'application lit le devis et propose une reconnaissance de chaque module.
3
Vérifiez / corrigez : pour chaque ligne, vous pouvez changer le modèle au menu déroulant si besoin (ex. un grand sanitaire qui a plein de configurations), ajuster le mobilier, exclure une ligne.
4
Cliquez « Générer » → vous obtenez un Excel par état + un ZIP à télécharger.
Astuce : l'application apprend. Si vous corrigez un modèle, elle s'en souviendra pour les prochains devis similaires. Retrouvez tout dans « Historique » et « Clients ».

👥4. Administration : comptes & mots de passe administrateur

Réservé aux comptes administrateur. Menu « Administration » (en bas à gauche).

Créer un compte (un commercial, un chauffeur…)

1
Administration → carte « Nouveau compte ».
2
Renseignez : Identifiant (ex. j.dupont), Nom affiché, Mot de passe (8 caractères minimum), et le Rôle.
3
Validez → le compte apparaît dans la liste « Comptes ».

Changer un mot de passe / désactiver un compte

Dans la liste « Comptes », à côté de chaque personne :

  • bouton « Mot de passe » → définir un nouveau mot de passe (utile si quelqu'un l'a oublié) ;
  • possibilité de désactiver un compte (ex. un salarié qui part) sans le supprimer.
Sécurité : l'application empêche de désactiver le dernier administrateur (pour ne jamais se retrouver enfermé dehors). Gardez toujours au moins 2 comptes admin par prudence. Les mots de passe sont stockés chiffrés (jamais en clair).

Les 3 rôles

RôlePeut faire
administrateurTout : générer, gérer les clients, gérer les comptes & mots de passe, réglages (société, logo, e-mail).
utilisateur (commercial / bureau)Générer les états des lieux, consulter clients / chantiers / historique. Pas d'accès à l'administration.
chauffeurUniquement ses constats sur le terrain (voir §6). Accès très limité.

💻5. Installer sur un nouveau poste

L'application et les données vivent déjà sur le serveur bureautique. Pour l'utiliser depuis un autre ordinateur du réseau, il faut une petite mise en place une seule fois (≈ 15 min) — idéalement par votre informaticien, ou avec l'aide de Claude :

1
Installer Python 3.12 (gratuit) sur le poste.
2
Récupérer le code (déjà sauvegardé en ligne sur GitHub, ou copié depuis le serveur).
3
Créer l'environnement (2 commandes) : 
py -3.12 -m venv .venv
.venv\Scripts\pip install -r requirements.txt
4
Créer un raccourci Bureau qui lance l'application (l'outil Creer un raccourci Bureau.bat le fait). Les données restent celles du serveur (mêmes clients, même connexion).
💡 Le plus simple pour reprendre le projet : ouvrir Claude (ou une autre IA) directement dans le dossier de l'application. Le fichier CLAUDE.md contient tout le contexte : l'IA comprend le projet et peut faire l'installation ou les évolutions.

🚚6. L'espace chauffeurs prochaine étape à brancher

Ce que c'est : un espace pensé pour les chauffeurs sur le chantier, depuis leur téléphone. Il est déjà développé dans l'application — il reste juste à le mettre en service.

Ce que le chauffeur pourra faire

  • Retrouver le client et le chantier, ouvrir l'état des lieux du module.
  • Faire le constat en 2 temps : Début de location (départ) et Fin de location (retour).
  • Pour chaque partie du module : cocher Bon / Sale / Cassé + une note.
  • Prendre des photos (compressées automatiquement pour la 4G) et faire signer le client du doigt — la signature s'insère directement dans le fichier Excel.
  • Envoyer la copie signée par e-mail au client depuis le chantier.
  • Installer l'appli sur le téléphone comme une vraie application (« Ajouter à l'écran d'accueil »).
Ce qu'il reste à faire pour l'activer : l'espace chauffeurs fonctionne depuis un téléphone en 4G, donc l'application doit être accessible en ligne (mise sur un petit serveur web sécurisé). Une fois en ligne :
  1. dans Administration → « Accès à distance », on renseigne l'adresse de l'application ;
  2. un QR code apparaît ; les chauffeurs le scannent avec leur téléphone ;
  3. ils se connectent avec leur compte chauffeur et c'est prêt.
Tout est déjà prévu côté application (le rôle chauffeur, le mode constat, le QR, la configuration e-mail). La marche à suivre technique pour la mise en ligne est documentée pour votre informaticien.

🛟7. En cas de souci

ProblèmeQue faire
La fenêtre ne s'ouvre pas / affiche une vieille versionFermez toutes les fenêtres de l'application, puis relancez par le raccourci Bureau.
« Lecture du devis impossible »Vérifiez que le fichier est bien un PDF lisible. Réessayez. Si ça persiste, prévenez le support (ça peut venir de la clé de lecture IA ou d'internet).
Mot de passe oubliéUn administrateur le réinitialise dans Administration → Comptes → « Mot de passe ».
Un document sort avec le mauvais modèleDans l'écran de vérification, changez le modèle au menu déroulant avant de générer.
Sauvegardes : vos données sont sauvegardées chaque jour (base + photos), avec une copie automatique sur OneDrive. Le code de l'application est sauvegardé sur GitHub. Rien n'est perdu.
